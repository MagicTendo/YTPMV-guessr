# YTPMV guessr

![YTPMV guessr logo](https://ytpmv.rf.gd/assets/images/ytpmv-guessr-logo.png)

> *A GeoGuessr-like guessing game with YTPMVs !*


## 🛠️ Features

The game will choose a random YTPMV from [otodb.net](https://otodb.net) and give a player to play it. The goal is to find the creator(s), the source(s) and the song(s) of the YTPMV. When either every answers has been found, the timer runned out or the user requested to see the answer, the answer with the title, the creator(s), the thumbnail, the source(s) and the song(s) will be revealed.

The game has multiple settings :

- A toggle for safe mode (hidding sensible sources).
- 5 game modes
    - Classic, any YTPMV can be choosen.
    - Collab, only collaborations or collaboration parts will be choosen.
    - Multisource, only YTPMVs marked as using multiple sources will be choosen.
    - Sources only, only the sources has to be guessed.
    - Songs only, only the songs has to be guessed.
- A maximum number of rounds, ranging from 3 to 25.
- A timer, ranging from none to 10 minutes.
